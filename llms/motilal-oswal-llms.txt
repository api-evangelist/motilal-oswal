- Built on AEM Edge Delivery Services (EDS) with WYSIWYG authoring
- Frontend: Vanilla JS, CSS — no framework dependencies
- Node.js 18.3.x or newer required
- AEM Cloud Service release 2024.8 or newer (>= 17465)
